Технические требования

Проверьте требования к оборудованию перед подключением.

Внимание! Перед приобретением программ Стандарт-Н рекомендуется ознакомиться с предъявленными техническими требованиями, чтобы быть уверенным в поддержке вашего оборудования.

В соответствии с положениями 54-ФЗ все наши программы поддерживают работу новых ККТ (онлайн-кассы).

 Скачать технические требования в формате PDF.

Компьютер

  • Системный блок
  • Ноутбук
  • Клавиатура (желательно с правой цифровой клавиатурой) + мышь
  • Принтер
  • Источник бесперебойного питания 

Фискальный регистратор (ККМ)*

Программа Стандарт-Н поддерживает фискальные регистраторы с USB-подключением и через COM-порты. Фискальный регистратор обеспечивает переход на онлайн кассу согласно 54-ФЗ для РФ. Рекомендуемое оборудование - это марки Атол или Штрих-М.

Терминал сбора данных*

Программа автоматизации Стандарт-Н позволяет проводить ревизию несколькими способами:

  • Вручную (персонал сам вводит все данные по остаткам в программу);
  • По штрих-коду;
  • С использованием терминала сбора данных (ТСД)
  • Приложение Стандарт-Н для Андроида (Сотрудниками скачивается приложение на смартфон на базе Андроид, программа автоматически синхронизируется с базой. Сотрудник проводит считывание штрих-кодов с помощью встроенной камеры телефона или USB-сканером через проходник. Данные отображаются в режиме онлайн, далее выгружаются в базу)

Для проведения ревизии компания Стандарт-Н может предоставить ТСД в аренду.

Табло покупателя*

Рекомендуемое табло покупателя - с поддержкой драйвера АТОЛ.
Для дисплеев производства НЕ АТОЛ, требуется приобретать лицензию.

Торговые весы с печатью штрих-этикеток, принтер штрих-кода

Рекомендуемые – весы компании CAS (CAS CL5000 Jr, CAS ER Jr, CAS LP, CAS AP,CAS ER), ШТРИХ-ПРИНТ, Масса К, METTELER TOLEDO, DIGI SM-300.

Интернет

Скорость от 1MBPS – достаточная скорость для обеспечения надёжного интернет-соединения.

Примечание: Для установки АРМ Сводный менеджер в интерфейсе 1с необходимо наличие лицензии на платформу 1с 8.3 и microsoft sql server от 2005 и выше (если розничных точек более 5).

* - это оборудование не является обязательным.
