Дополнительные условия для работы с маркировкой

Уважаемые клиенты!

На промышленном контуре ФГИС МДЛП изменяется цепочка сертификации для доступа к https://api.mdlp.crpt.ru. БЕЗ этого сертификата маркировка работать не будет!

Для того чтобы маркировка продолжила работу в корректном режиме, требуется не позднее 23.08.2021 18:00 по Московскому времени добавить дополнительный сертификат Тензор https://update.sbis.ru/ereport/cert/basic/tensorca-2021_gost2012.cer в хранилище сертификатов "Промежуточные центры сертификации".

Если у вас не получается его скачать, то файл с сертификатом можно найти на сайте Честного Знака или обратиться в техническую поддержку Стандарт-Н.

Итак, вы скачали себе файл. Первым делом вам нужно его запустить (кликнуть на него дважды мышью).  Потом нажимаем «Открыть».

После этого откроется окно. В этом окне нажимаем «Установить сертификат»:

После следуем инструкции, нажимаем Текущий пользователь и затем «Далее»:

Обязательно выбираем пункт «Поместить все сертификаты в следующее хранилище». Затем нажимаем «Обзор» и выбираем «Промежуточные центры сертификации».

Заканчиваем установку, нажимаем «Готово»:

Инструкцию по установке можно скачать по ссылке: Инструкция по установке ключа
