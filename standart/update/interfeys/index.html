Интерфейс

Интерфейс - это первое, с чем знакомится пользователь любой программы, согласны? 

Интерфейс - управляющие элементы программы, с помощью которых пользователь выполняет различные действия. Говоря простыми словами – это те кнопки и окошки, которые вы используете для того, чтобы программа совершала нужные вам действия. 

Взаимодействие пользователя с программой должно быть быстрым, легким и интуитивно-понятным. Именно поэтому интерфейс программы Стандарт-Н устроен следующим образом: 

  • Вся информация находится на одном экране 
  • Можно с легкостью менять границы окон, колонок, шрифт 
  • Интерактивная подкраска. Программа автоматически подкрашивает значения, на которые нужно обратить внимание: привышение наценки, фальсификат и т.п. 
  • Введение горячих клавиш: наиболее часто-используемые функции, подсказки для действий
